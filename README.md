## Overview

REFramework is a modding framework for games built on Capcom's RE Engine, supporting Resident Evil 2 Remake, RE3 Remake, RE4 Remake, RE Village, Devil May Cry 5, Monster Hunter Rise, Monster Hunter Wilds, and Dragon's Dogma 2. It provides a Lua scripting API with full access to in-game C++ types, a Dear ImGui overlay for developer tools, VR injection for native-quality virtual reality support, and serves as the foundation for the majority of RE Engine community mods.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **REFramework** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Lua Scripting** | Full game-object access via Lua API with live type reflection |
| **Dear ImGui Overlay** | In-game developer tools panel for mod creators and debugging |
| **VR Injection** | Native-quality VR support for supported RE Engine titles |
| **Multi-Game Support** | RE2R, RE3R, RE4R, RE Village, DMC5, MH Rise, MH Wilds, DD2 |
